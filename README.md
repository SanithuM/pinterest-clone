# 📌 Pinterest Clone - Wallpaper App

A simple Pinterest-inspired web app built with **React** and **Tailwind CSS**.  
Users can browse randomized images and embedded videos with autoplay support, search wallpapers, and experience a clean UI similar to Pinterest.

---

## 🚀 Features
- 🔍 Search bar for wallpapers  
- 🖼️ Responsive image cards with hover effects  
- 🎥 Support for videos (autoplay, loop, iframe embeds)  
- 🎨 Modern UI with Tailwind CSS  
- 📱 Fully responsive design  
- 📌 Sticky navbar with Pinterest logo  

---

## 🛠️ Tech Stack
- **React** (Frontend library)  
- **Tailwind CSS** (Styling)  
- **React Icons** (Icons)
